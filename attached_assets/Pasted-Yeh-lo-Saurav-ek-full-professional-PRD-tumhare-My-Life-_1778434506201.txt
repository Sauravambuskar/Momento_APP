## 2. 🎯 Problem Statement

Humans are terrible at feeling the passage of time. A 90-year life sounds long — until you see it as **4,680 dots on a grid**. *Memento* makes mortality tangible, turning abstract years into a visual weekly grid that users can interact with, annotate, and reflect on — driving intentional living.

***

## 3. 🖥️ Core Features (Screens)

### Screen 1 — Onboarding
- Minimal 3-step splash with **blur/frosted glass cards**
- Step 1: Enter name + date of birth
- Step 2: Set expected lifespan (default 80, slider up to 100)
- Step 3: Choose accent color (White / Warm / Cool — monochrome only)
- Smooth **Reanimated 3** entrance animations — no jarring transitions

### Screen 2 — The Grid (Main Screen)
- **SVG dot grid** — 52 columns (weeks) × lifespan rows (years)
- Filled circles = weeks lived (solid black)
- Empty circles = weeks remaining (outlined, frosted)
- **Current week dot** pulses with a subtle glow animation
- Pinch-to-zoom on the grid
- Tap any dot → opens **Week Detail Modal**

### Screen 3 — Week Detail Modal
- Shows: Week number, Year, Date range
- User can add a **"Memory Tag"** — emoji + short text (e.g. 🚀 Shipped my first SaaS)
- Color-code weeks by category: Work, Health, Travel, Learning, Personal
- Saved to MMKV locally + synced to Supabase if logged in

### Screen 4 — Stats Dashboard
- **Weeks lived** vs **Weeks remaining** — donut chart
- % of life completed
- Current streak: "You've tagged X weeks in a row"
- Motivational quote (rotates daily — pre-seeded, no API dependency)

### Screen 5 — Profile & Settings
- Avatar + name
- Edit birth date / lifespan
- Notification settings (weekly reminder: "Log your week")
- Export grid as **high-res PNG or PDF**
- Account sync toggle (Supabase login)

## 5. 🗄️ Database Schema (Supabase)

```sql
-- Users
users (
  id uuid PRIMARY KEY,
  name text,
  birth_date date,
  expected_lifespan int DEFAULT 80,
  accent_theme text DEFAULT 'white',
  created_at timestamptz
)

-- Week Entries
week_entries (
  id uuid PRIMARY KEY,
  user_id uuid REFERENCES users(id),
  week_number int,        -- e.g. 1432
  year_number int,        -- e.g. 27
  week_start_date date,
  emoji text,             -- e.g. "🚀"
  note text,              -- short memory tag
  category text,          -- work | health | travel | learning | personal
  color_hex text,         -- monochrome shade
  created_at timestamptz,
  updated_at timestamptz
)
```

**MMKV Local Schema** mirrors the same structure — synced to Supabase on next online session via **Legend-State sync plugin**. [supabase](https://supabase.com/blog/local-first-expo-legend-state)

## 8. 🔢 Core Logic — Week Calculator

```typescript
// lib/weekUtils.ts
import { differenceInWeeks, addWeeks, format } from 'date-fns';

export const getLifeStats = (birthDate: Date, lifespan: number) => {
  const totalWeeks = lifespan * 52;
  const weeksLived = differenceInWeeks(new Date(), birthDate);
  const weeksRemaining = totalWeeks - weeksLived;
  const percentLived = ((weeksLived / totalWeeks) * 100).toFixed(1);

  return { totalWeeks, weeksLived, weeksRemaining, percentLived };
};

export const getWeekDateRange = (birthDate: Date, weekNum: number) => {
  const start = addWeeks(birthDate, weekNum - 1);
  const end = addWeeks(start, 1);
  return {
    start: format(start, 'MMM d, yyyy'),
    end: format(end, 'MMM d, yyyy'),
  };
};
```
